# AIML Practical Assignment 5
## Ensemble Learning and Performance Evaluation

### Objective
To implement and compare Stacking, AdaBoost,
Hard Voting and Soft Voting ensemble techniques
with individual machine learning classifiers.

### Dataset
Synthetic Retail Sales Dataset containing
10,000 records and 10 attributes.

Target variable: category

Classes:
- Clothing
- Electronics
- Furniture
- Grocery
- Sports

### Algorithms Implemented
1. Support Vector Machine
2. Decision Tree
3. K-Nearest Neighbors
4. Naive Bayes
5. Stacking Ensemble
6. AdaBoost Ensemble
7. Hard Voting
8. Soft Voting

### Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

### Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Log Loss

### Execution
Open the notebook in Google Colab,
upload the dataset and run all cells.

### Results
The performance comparison is available
in ensemble_comparison_results.csv.
